Automated Brain Tumor Classification from MRI Images using Convolutional Neural Networks
Project Overview

This project presents a deep learning-based framework for automated brain tumor classification using MRI images. The system utilizes Convolutional Neural Networks (CNNs) to identify and classify different types of brain tumors from medical imaging data.

The project involves complete medical imaging workflow development including data preprocessing, image normalization, CNN model training, evaluation, visualization, and MRI prediction analysis.

Dataset

The project uses a publicly available Brain Tumor MRI dataset containing four classification categories:

Glioma
Meningioma
Pituitary Tumor
No Tumor

MRI images were resized, normalized, and processed before being used for deep learning model training.

The trained CNN model achieved high classification accuracy on MRI test images and demonstrated strong performance in distinguishing different brain tumor categories.
